# BrainCloud

Your digital second brain. Capture notes, tweets, videos, and documents in one seamless workspace designed for clarity.

## Features

- **Second Brain**: Organize your digital life with a centralized dashboard.
- **Content Integration**: Seamlessly add tweets, videos, and documents.
- **Modern UI**: Built with a dark, premium aesthetic using TailwindCSS and Framer Motion.
- **Secure**: Authentication powered by a custom auth store.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: TailwindCSS v4
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view the app.
